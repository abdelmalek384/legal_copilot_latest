## Schedule count reconciliation

The secondary HTML transcription and the Gazette-layout PDF show the serial numbering reaching **435** at the final entry. Earlier repository notes described the annex as a “434-occupation” schedule. Treat the count as unresolved until the full table is parsed, unique rows are counted, duplicate serials/codes are checked, and the original Gazette page images are reviewed. A highest serial number is not by itself proof of the number of distinct entries.

## OCR and transcription cautions

- The PDF's searchable text layer is not authoritative for the occupation codes. Visual page images show that some extracted/searchable codes differ from the image, so any parser must preserve image-reviewed corrections separately from raw OCR.
- The LAW HUB HTML schedule is a useful discovery/transcription source but cannot be treated as identical to the Gazette page images; the nine code differences above demonstrate the risk.
- The PDF is hosted on a third-party domain and bears a visible watermark. It is not an authenticated Amiri Press binary. No rights clearance for redistribution, embedding, or commercial reuse is established.
- This audit does not establish whether any listed occupation remains subject to the same licensing/measurement requirements after subsequent decisions, amendments, or administrative updates.
